# Hafeez WebStudio — portfolio website

Pure static site (HTML, CSS, JS). No build step needed.

## Host it
**GitHub:** create a repo, upload everything in this folder, then Settings → Pages → deploy from `main` / root.
**Vercel:** import the GitHub repo (Framework: *Other*, no build command, output directory `.`) or drag the folder into vercel.com/new.

## After you have your live address
Search & replace `https://hafeezwebstudio.vercel.app` in all files (index, about, services, projects, reviews, terms, contact, sitemap.xml, robots.txt) with your real address, so canonical links and the sitemap are correct. Then submit `sitemap.xml` in Google Search Console.
